## Getting Started

1. Download `CodeLens.zip`.
2. Extract the ZIP archive.
3. Locate `CodeLens.exe`.
4. Create a `.env` file beside the executable.
5. Add your OpenRouter API key:

```env
OPENROUTER_API_KEY=sk-or-v1-YOUR_API_KEY
```

6. Save the file and launch `CodeLens.exe`.

Get your API key: https://openrouter.ai/keys

**Note:** AI-powered analysis requires an active internet connection and a valid OpenRouter API key. Never share your API key publicly.

## About CodeLens

CodeLens is an AI-powered source code analysis application that combines static analysis and OpenRouter AI to help developers:

- Analyze source code projects.
- Identify potential security risks.
- Detect exact duplicate files.
- Generate AI-powered project summaries.
- Review code quality and maintainability.
- Generate comprehensive PDF analysis reports.
